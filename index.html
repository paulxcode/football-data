European Football Analysis

An exploratory data analysis of matches across 11 European leagues (2008–2016)

Data & Methodology

How this analysis was conducted, from raw data to insights

Data Source

European Soccer Database by Hugo Mathien, hosted on Hugging Face. Contains match results, player attributes, team info, and betting odds from 11 European leagues across 8 seasons.

Tools & Libraries

  • Python for data processing and modeling
  • Pandas and NumPy for data wrangling
  • SQLite for database queries
  • Scikit-learn for the Random Forest classifier
  • Plotly for interactive visualizations

Process

  • SQL extraction from relational database
  • Data cleaning & feature engineering
  • Exploratory data analysis
  • Statistical summaries & aggregation
  • Predictive modeling with betting odds

Season Trends

Goal scoring and home advantage stayed remarkably stable from 2008 to 2016

Key insight: Average goals per match fluctuated in a narrow band (2.5–2.8). Home win rate held consistently around 45–48% every season; these patterns are deeply structural, not cyclical.

Player Analysis

Tracking players from goal contributions to career arcs across 8 seasons

Key insight: Messi and Ronaldo's production tracked across 8 seasons using actual match event data. Messi edges Ronaldo in total G+A (384 vs 355), but Ronaldo's peak season (2014–15: 63 G+A) narrowly beats Messi's best (2012–13: 60 G+A). Both maintained elite production for nearly a decade, a longevity unmatched in modern football.

Model Performance

Key insight: Betting odds encode market knowledge remarkably well; the model achieves accuracy. Draws are the hardest to predict (low recall), as they're the least common outcome and often have ambiguous odds.
